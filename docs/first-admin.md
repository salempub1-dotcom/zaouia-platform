# إنشاء أول مدير على Render

هذه الخطوة لا تتطلب Shell، ولا تنشئ حسابًا بكلمة مرور افتراضية.

1. افتح خدمة zaouia-web في Render ثم Environment.
2. أضف ZAOUIA_ADMIN_EMAIL ببريدك.
3. أضف ZAOUIA_ADMIN_PASSWORD بكلمة مرور خاصة وفريدة من 12 حرفًا أو أكثر.
4. اختر Save, rebuild, and deploy لتضمين أمر التهيئة الجديد.
5. انتظر Live وابحث في السجل عن Initial administrator created.
6. سجل الدخول من /admin/ ببريدك وكلمة المرور.
7. احذف المتغيرين من Render بعد نجاح الدخول ثم Save and deploy.

لا تضع كلمة المرور في GitHub أو المحادثة أو صور الشاشة.
يعيد التشغيل اللاحق استخدام الحساب دون تغيير كلمة مروره.
يرفض الأمر ترقية حساب عضو موجود أو إنشاء مدير ثانٍ؛ استخدم المدير الحالي لذلك.
الإعداد غير الصحيح يوقف بدء الخدمة برسالة عامة دون طباعة بيانات الدخول.

## أول محتوى

من لوحة الإدارة أضف الشيخ والتصنيف ثم المحتوى، وحدد حالة النشر وتاريخه.
ابدأ بعنوان ووصف ورابط YouTube تملكه أو لديك إذن بنشره، ثم اختبر ظهوره والبحث عنه.
لا يضيف أمر التهيئة أي محتوى تجريبي إلى الموقع.
تخزين الملفات المحلي في Render المجاني مؤقت؛ أعدّ S3 قبل اعتماد المكتبة للملفات الدائمة.
